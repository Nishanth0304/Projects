Working with HTML5 Lists

This page demonstrates the three core list types available in HTML5.

1. Unordered List (ul)

Used for items where the specific order does not matter. It defaults to bullet points.

  • Grocery items:
    • Milk
    • Bread
    • Eggs
  • To-do task items
  • Webpage navigation links

2. Ordered List (ol)

Used for items that follow a specific sequence, steps, or ranking. It defaults to numbers.

  1. Gather your coding materials
  2. Open your text editor
  3. Write your basic HTML structure:
    1. Create the doctype
    2. Add the html tags
    3. Build the head and body
  4. Save the file as index.html
  5. Open it in a web browser to view

3. Description List (dl)

Used for groupings of terms and their corresponding descriptions (like a glossary or dictionary index).

ul
The Unordered List tag used to hold bulleted list items.
ol
The Ordered List tag used to hold numbered, sequenced list items.
li
The List Item tag, required inside both unordered and ordered lists to define each point.
